# dailynews-featured-image

**ปกข่าวเดลินิวส์:** เครื่องมือทำภาพ Featured Image สำหรับข่าวของเดลินิวส์

เว็บแอปทำรูปปกข่าวจาก Template Photoshop ของเดลินิวส์ เลือกได้ 2 แบบจากแท็บด้านบน

| แท็บ | ขนาด | ไฟล์ที่ได้ |
|---|---|---|
| **Website** | 1280 × 720 px | JPG 72 ppi **ไม่เกิน 150 KB** (ลดคุณภาพให้อัตโนมัติเท่าที่จำเป็น) |
| **Facebook** | 1440 × 1800 px | JPG 72 ppi |

ใส่รูป พิมพ์ข้อความ แล้วดาวน์โหลดเป็น JPG ได้ทันที ทุกอย่างทำงานในเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์หลังบ้าน และไม่อัปโหลดรูปออกไปไหน
สลับแท็บแล้วรูปและเลเยอร์ที่ทำอยู่ตามไปด้วย โดยพาดหัวหลักและสีโลโก้ใช้ร่วมกันทั้งสองแพลตฟอร์ม
ส่วนตำแหน่ง ขนาด ครอป กรอบ เงา Gradient Mask และการจัดวาง เก็บแยกตามแพลตฟอร์ม สลับไปมาแล้วกลับมาเหมือนเดิม
ชี้เมาส์ที่ขนาดภาพมุมขวาของแถบเครื่องมือเพื่อดูรายละเอียดไฟล์ (ขนาด, PPI, โหมดสี, ขนาดไฟล์สูงสุด)

เวอร์ชันปัจจุบัน: **v1.8.0**

## ความสามารถ

**รูป**
- ใส่ได้หลายรูป (อัปโหลด ลากมาวาง หรือวางจากคลิปบอร์ด) ชื่อรูปในรายการใช้ชื่อไฟล์
- ลากสลับลำดับรูปที่จุดจับ ⋮⋮ หรือใช้ลูกศรขึ้น/ลง
- มีรูปเดียว รูปจะล็อคให้เต็มเฟรมเสมอ ถ้ามี 2 รูปขึ้นไป รูปล่างสุดเลื่อนและย่อได้อิสระ
- ปุ่มรูปตาซ่อน/แสดงรูป (เก็บแยกตามแพลตฟอร์ม) และปุ่มทำสำเนารูป
- จัดวางอัตโนมัติ: แบบอิสระ, ไล่เฉดซ้าย–ขวา / บน–ล่าง, บน/ล่าง, ซ้าย/ขวา, 3 แถว, 3 แนวตั้ง, สามเหลี่ยม, 2 บน 1 ล่าง, 1 ซ้าย 2 ขวา, 2 ซ้าย 1 ขวา, ตาราง 2×2 ฯลฯ พร้อมปรับระยะห่าง แสดงเป็นแถวเดียวมีปุ่มเลื่อนซ้าย–ขวา และปุ่ม "ดูทั้งหมด"
- คลิกบนภาพเพื่อเลือกรูป ลากเพื่อเลื่อน หมุนล้อเมาส์เพื่อซูม
- ปรับซูม หมุน (±90° ได้ในคลิกเดียว) และความทึบ (Opacity)
- ครอปด้วยตัวเลื่อน 2 จุดพร้อมภาพตัวอย่าง มีสวิตช์ "ขยายให้เต็มกรอบหลังครอป"
- **ลบพื้นหลัง** ในเครื่อง ประมวลผลด้วยการ์ดจอผ่าน WebGL2 (ดูหัวข้อ "ลบพื้นหลังทำงานอย่างไร")
- กรอบรูป: ไม่มีเส้น / ขาว / ดำ / ชมพู #EC008C / กำหนดเอง (ตารางสีในหน้า, HEX, RGB, HSL, OKLCH, Eyedropper และสีล่าสุด 5 สี)
  - สไตล์: Simple, Metal, Drop Shadow, Double Frame
  - รูปทรง (ปุ่มสัญลักษณ์): สี่เหลี่ยม, มุมมน, วงกลม, สี่เหลี่ยมด้านขนาน, รูปหลายเหลี่ยมกำหนดเอง
- เงาใต้รูป: ทิศทาง (วงหมุน), ระยะ, ความฟุ้ง, ความเข้ม
- Gradient Mask: ตัวเลื่อน 2 จุดแนวนอนและแนวตั้ง จางได้พร้อมกันทุกด้าน พร้อมภาพตัวอย่างส่วนที่ถูกตัดออก
- ปุ่ม "รีเซ็ตทั้งหมด" คืนค่าการปรับของรูปที่เลือก

**ข้อความและองค์ประกอบของ Template**
- Facebook: ข้อความ 3 บรรทัด (บรรทัดบน / พาดหัวหลัก / บรรทัดล่าง) ฟอนต์ Kanit ตามขนาด น้ำหนัก และเงาใน Template บรรทัดที่ยาวเกินกรอบจะย่อลงเอง โดยขอบล่างของบรรทัดล่างอยู่กับที่ และระยะห่างระหว่างบรรทัดคงเดิม
- Website: ใช้เฉพาะพาดหัวหลัก 1 บรรทัด (Kanit SemiBold, tracking 20, เงาตาม Template) ย่อลงเองเมื่อยาวเกิน ไม่ตกขอบ และยังอยู่เหนือเส้นชมพู
- ปุ่ม "วาง" / "ลบ" แยกทีละบรรทัด, "ข้อความตัวอย่าง" (ใช้ข้อความเริ่มต้นที่ตั้งไว้) และ "ลบทั้งหมด" (เฉพาะ Facebook)
- Facebook: วันที่แบบไทย (ปี พ.ศ.) เลือกจากปฏิทิน และแถบช่องทางโซเชียล (Website ไม่มีทั้งสองอย่าง)
- เลือกสีโลโก้ (ขาว/ชมพู) และเปิด–ปิดเงาโลโก้ได้ทั้งสองแท็บ
- เส้น: Facebook เลือกขาว/ชมพูได้ Website ใช้เส้นชมพูตาม Template

**การใช้งานทั่วไป**
- ย้อนกลับ / ทำซ้ำ 30 ครั้ง พร้อมรายการประวัติที่กดข้ามไปจุดไหนก็ได้ แต่ละรายการบอกค่าที่เปลี่ยน และมีปุ่มล้างประวัติ ประวัติแยกตามแพลตฟอร์ม และการสลับแพลตฟอร์มไม่ถูกบันทึก
- ดาวน์โหลดเป็น JPG เสมอ ตั้งรูปแบบชื่อไฟล์แยกแต่ละแท็บได้ (ค่าเริ่มต้น `{YYYY}{MM}{DD}{HH}{mm}-dailynews-website` และ `…-dailynews-facebook`)
- Alternative Text ฝังในไฟล์ JPG (XMP `Iptc4xmpCore:AltTextAccessibility` + `dc:description`, EXIF ImageDescription/XPTitle และ IPTC Caption) กรอกอัตโนมัติจากพาดหัวหลัก หรือปิดสวิตช์เพื่อพิมพ์เอง
- สลับแพลตฟอร์มแล้วรูปตามไปด้วย แต่ตำแหน่ง ขนาด ครอป กรอบ เงา Gradient Mask การจัดวาง และการซ่อนรูป เก็บแยกตามแพลตฟอร์ม
- ตั้งค่า: ขนาดตัวอักษรของหน้าจอ, ธีมสว่าง/มืด, จำหรือล็อคสีโลโก้ เงาโลโก้ และสีเส้น, แก้คีย์ลัด, เปิด Gradient Mask อัตโนมัติ, ข้อความเริ่มต้น, รูปแบบชื่อไฟล์ (จำไว้ใน `localStorage` ของเบราว์เซอร์)

## เริ่มใช้งาน

แอปต้องเปิดผ่าน HTTP(S) เพราะมีการโหลดไฟล์โมเดลด้วย `fetch()` การดับเบิลคลิกเปิด `index.html` ตรงๆ แบบ `file://` จะใช้ฟังก์ชันลบพื้นหลังไม่ได้

### รันในเครื่อง

```bash
cd dailynews-featured-image
python3 -m http.server 8000
# เปิด http://localhost:8000
```

### เผยแพร่ด้วย GitHub Pages

1. Push ไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น GitHub repository `dailynews-featured-image`
2. ไปที่ **Settings → Pages**
3. ที่ **Source** เลือก *Deploy from a branch* → branch `main` → โฟลเดอร์ `/ (root)` → **Save**
4. รอสักครู่ แอปจะอยู่ที่ `https://<username>.github.io/dailynews-featured-image/`

ใช้ได้กับ static hosting ทุกเจ้า (Netlify, Vercel, Cloudflare Pages, เซิร์ฟเวอร์ของบริษัท) แค่อัปโหลดทั้งโฟลเดอร์

├── web_line.png          Website: เส้นชมพูใต้ข้อความ

├── line_white.png        เส้นเหนือแถบโซเชียล สีขาว
├── line_pink.png         เส้นเหนือแถบโซเชียล สีชมพู

│   ├── silueta.json      ลำดับการคำนวณ + ขนาด tensor
│   ├── bias.wasm         bias (float32)
│   └── w-0.wasm … w-2.wasm   น้ำหนักโมเดล (uint8) แบ่งเป็น 3 ไฟล์
├── src/
│   ├── index.src.html    ซอร์สของหน้าแอป (HTML + CSS + JS)
│   └── glnet.js          เอนจินคำนวณโมเดลบน WebGL2
├── tools/
│   ├── onnxpb.py         ตัวอ่านไฟล์ ONNX (ไม่ต้องติดตั้งไลบรารีเพิ่ม)
│   ├── convert_model.py  แปลง silueta.onnx → silueta.json + weights.u8 + bias.f32
│   └── split_weights.py  แบ่งน้ำหนักเป็นไฟล์ย่อยลงโฟลเดอร์ model/

ไฟล์โมเดลใช้นามสกุล `.wasm` เพื่อให้ hosting บางเจ้าเสิร์ฟเป็นไฟล์ไบนารีได้แน่นอน แต่เนื้อไฟล์เป็นข้อมูลดิบ ไม่ใช่ WebAssembly แต่ละไฟล์เล็กกว่า 15 MB จึงไม่ต้องใช้ Git LFS

## แก้ไขโค้ด

แก้ที่ `src/index.src.html` หรือ `src/glnet.js` แล้ว build ใหม่:

```bash
python3 build.py
```

ค่าที่มักต้องแก้ อยู่ใน `src/index.src.html`:

| ค่า | ใช้ทำอะไร |
|---|---|
| `VERSION`, `CHANGELOG` | เลขเวอร์ชันและรายการในหน้า Changelog |
| `TPL.facebook`, `TPL.website` | ทุกอย่างของแต่ละ Template: ขนาดภาพ, ตำแหน่ง/ขนาดฟอนต์/เงาของข้อความ (`lines`), วันที่, โซเชียล, โลโก้และเงาโลโก้, เส้น, `maxW` ความกว้างสูงสุดของข้อความ, `sizeCap` ขนาดไฟล์สูงสุด (byte) |

## ลบพื้นหลังทำงานอย่างไร

- ใช้โมเดล **silueta** จาก [rembg](https://github.com/danielgatis/rembg) ซึ่งเป็น U²-Net แบบ quantize แล้ว (ประมาณ 44 MB)
- `tools/convert_model.py` แปลงไฟล์ ONNX เป็นรายการคำสั่ง 253 ขั้น (conv, max-pool, resize, concat, add, sigmoid) และแพ็กน้ำหนักเป็น texture RGBA8
- `src/glnet.js` คำนวณโมเดลด้วย fragment shader ของ WebGL2 จึงไม่ต้องใช้ WebAssembly หรือ Web Worker
  - แบ่งงาน convolution ใหญ่เป็นหลายรอบเล็ก เพื่อไม่ให้การ์ดจอค้างหรือ timeout
  - ผลลัพธ์ตรงกับ ONNX Runtime (ต่างกันไม่ถึง 0.2%)
- ครั้งแรกที่กดจะโหลดโมเดลประมาณ 44 MB หลังจากนั้นเบราว์เซอร์จะแคชไว้
- ต้องใช้เบราว์เซอร์ที่รองรับ WebGL2 และ float render target (Chrome, Edge, Firefox, Safari รุ่นปัจจุบัน)

### สร้างไฟล์โมเดลใหม่ (ไม่จำเป็น ถ้าใช้ไฟล์ใน `model/` อยู่แล้ว)

```bash
# ต้องมี Python 3 และ numpy
curl -L -o silueta.onnx https://github.com/danielgatis/rembg/releases/download/v0.0.0/silueta.onnx
python3 tools/convert_model.py silueta.onnx    # ได้ silueta.json, weights.u8, bias.f32
python3 tools/split_weights.py .               # เขียนลง model/
```

## ข้อจำกัดที่ควรรู้

- **ปุ่ม "วาง":** เบราว์เซอร์บางตัว (หรือเมื่อฝังใน iframe) ไม่ให้เว็บอ่านคลิปบอร์ดโดยตรง ในกรณีนี้แอปจะเลือกข้อความในช่องไว้และแจ้งให้กด `Ctrl+V` / `⌘V` แทน
- **Eyedropper:** ใช้ตัวดูดสีของระบบถ้าเบราว์เซอร์รองรับ (Chrome, Edge) ถ้าไม่รองรับจะให้คลิกดูดสีจากภาพตัวอย่างแทน
- **ไอคอนโซเชียล:** ใน PSB เป็นภาพขนาดเล็ก (~36 px) จึงถูกขยาย 1.33 เท่า ดูใกล้ๆ จะนุ่มกว่าส่วนอื่นเล็กน้อย
- **การตั้งค่า:** จำไว้ใน `localStorage` ของเบราว์เซอร์ที่ใช้ตั้งเท่านั้น ไม่ข้ามเครื่องหรือข้ามเบราว์เซอร์
- **150 KB ของ Website:** นับเป็น 150,000 ไบต์ ภาพที่มีรายละเอียดมากจะถูกลดคุณภาพ JPG ลงจนพอดี ขนาดและคุณภาพที่ได้จะแจ้งหลังดาวน์โหลด
