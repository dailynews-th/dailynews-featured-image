# dailynews-featured-image

**ปกข่าวเดลินิวส์:** เครื่องมือทำภาพ Featured Image สำหรับข่าวของเดลินิวส์

เว็บแอปทำรูปปกข่าวจาก Template Photoshop ของเดลินิวส์ เลือกได้ 2 แบบจากแท็บด้านบน

| แท็บ | ขนาด | ไฟล์ที่ได้ |
|---|---|---|
| **Website** | 1280 × 720 px | JPG 72 ppi **ไม่เกิน 150 KB** (ลดคุณภาพให้อัตโนมัติเท่าที่จำเป็น) |
| **Facebook** | 1440 × 1800 px | JPG 72 ppi |

ใส่รูป พิมพ์ข้อความ แล้วดาวน์โหลดเป็น JPG ได้ทันที ทุกอย่างทำงานในเบราว์เซอร์ ไม่มีเซิร์ฟเวอร์หลังบ้าน และไม่อัปโหลดรูปออกไปไหน
สลับแท็บแล้วรูปและเลเยอร์ที่ทำอยู่ตามไปด้วย โดยพาดหัวหลักและสีโลโก้ใช้ร่วมกันทั้งสองแพลตฟอร์ม
ส่วนตำแหน่ง ขนาด ครอป กรอบ เงา Gradient Mask และการจัดวาง เก็บแยกตามแพลตฟอร์ม สลับไปมาแล้วกลับมาเหมือนเดิม
ชี้เมาส์ที่ขนาดภาพมุมขวาของแถบเครื่องมือเพื่อดูรายละเอียดไฟล์ (ขนาด, PPI, โหมดสี, ขนาดไฟล์สูงสุด)

เวอร์ชันปัจจุบัน: **v1.13.1**

## ความสามารถ

**รูป**
- ใส่ได้หลายรูป (อัปโหลด ลากมาวาง หรือวางจากคลิปบอร์ด) ชื่อรูปในรายการใช้ชื่อไฟล์
- ลากสลับลำดับรูปที่จุดจับ ⋮⋮ หรือใช้ลูกศรขึ้น/ลง
- มีรูปเดียว ซูมออกได้จนเห็นทั้งรูป (เช่น รูปแนวตั้งเต็มความสูง) แต่ไม่เล็กกว่าพื้นที่ Artboard และเลื่อนได้ภายในกรอบ ถ้ามี 2 รูปขึ้นไป รูปล่างสุดเลื่อนและย่อได้อิสระ (ยกเว้นหน้า Crop & Resize ที่รูปเดียวก็ซูมและเลื่อนได้อิสระ)
- เมนู "พื้นหลังส่วนที่ขยาย" (แยกตามแพลตฟอร์ม ทุก Template): เบลอจากรูป (เลือกรูปที่ใช้ได้เมื่อมีหลายรูป ตัวปรับความเบลอ ขนาด หมุน ตำแหน่งพับเก็บไว้ และลากบนพื้นหลังในภาพหลักเพื่อเลื่อนได้) หรือใช้สีขาว ดำ สีอื่น มีปุ่มรีเซ็ต
- ซูมรูปบนภาพ: หมุนลูกกลิ้งเมาส์ หรือบนมือถือ/แท็บเล็ตใช้ 2 นิ้วถ่าง–หุบ (เลื่อนไปพร้อมกันได้)
- ชี้เมาส์หรือแตะที่รูป จะมีลูกศรที่มุมทั้ง 4 ของรูป ลากเพื่อหมุน (Shift = ทีละ 15°)
- ไม้บรรทัด (Ctrl+R) บอกพิกัด px ช่วงของรูปที่เลือก และตำแหน่งเมาส์
- ปุ่มรูปตาซ่อน/แสดงรูป (เก็บแยกตามแพลตฟอร์ม) และปุ่มทำสำเนารูป
- จัดวางอัตโนมัติ: แบบอิสระ, ไล่เฉดซ้าย–ขวา / บน–ล่าง, บน/ล่าง, ซ้าย/ขวา, 3 แถว, 3 แนวตั้ง, สามเหลี่ยม, 2 บน 1 ล่าง, 1 ซ้าย 2 ขวา, 2 ซ้าย 1 ขวา, ตาราง 2×2 ฯลฯ พร้อมปรับระยะห่าง แสดงเป็นแถวเดียวมีปุ่มเลื่อนซ้าย–ขวา และปุ่ม "ดูทั้งหมด"
- คลิกบนภาพเพื่อเลือกรูป ลากเพื่อเลื่อน หมุนล้อเมาส์เพื่อซูม
- ปรับซูม (ปุ่มพอดีความสูง / พอดีความกว้าง / เต็มกรอบ คีย์ลัด Shift+H / Shift+W / Shift+F) หมุน (±45°, ±90° และปุ่มรีเซ็ต) และความทึบ (Opacity)
- ตำแหน่งรูปภาพ: ช่อง X, Y, W, H (px บน Artboard) ปุ่มจัดชิดซ้าย / กึ่งกลาง / ขวา / บน / กึ่งกลาง / ล่าง และจัดกึ่งกลาง
- สวิตช์ ไม้บรรทัด และ Snap ขอบ อยู่แถวเดียวกัน (2 คอลัมน์) เหนือเมนูปรับรูป
- สไตล์กรอบรูปเลือกจากการ์ดที่มีภาพประกอบ (Simple / Metal / Drop Shadow / Double Frame)
- Snap ขอบเวลาลากรูป (ขอบ/กึ่งกลางของภาพและรูปอื่น มีเส้นนำยาวเลยขอบ Artboard และแสดงครบทุกขอบที่ตรงกัน เช่น รูปพอดีความกว้างจะขึ้นทั้งซ้ายและขวา กด Alt ค้างเพื่อไม่ Snap) เปิด–ปิดได้ที่สวิตช์ Snap ขอบ ข้างสวิตช์ไม้บรรทัด
- Gradient Mask มีรายการรูปให้กดเลือกรูปที่จะปรับ
- ครอปด้วยตัวเลื่อน 2 จุดพร้อมภาพตัวอย่าง สัดส่วนสำเร็จรูป อิสระ / 1:1 / 4:3 / 16:9 / 16:10 / 21:9 พร้อมปุ่มสลับแนวนอน–แนวตั้ง (3:4, 9:16, 10:16, 9:21) และสวิตช์ "ขยายให้เต็มกรอบหลังครอป"
- ปุ่ม "ดึงการตั้งค่ารูปจาก" แพลตฟอร์มอื่น (รูปที่เลือก หรือติ๊ก "ทุกรูป") เลือกได้ใน "เลือกสิ่งที่จะดึง": ครอป กรอบ เงา Gradient Mask ความทึบ หมุน ตำแหน่งและขนาด การซ่อนรูป (ค่าเริ่มต้น 5 อย่างแรก)
- **ลบพื้นหลัง** ในเครื่อง ประมวลผลด้วยการ์ดจอผ่าน WebGL2 (ดูหัวข้อ "ลบพื้นหลังทำงานอย่างไร")
- กรอบรูป: ไม่มีเส้น / ขาว / ดำ / ชมพู #EC008C / กำหนดเอง (ตารางสีในหน้า, HEX, RGB, HSL, OKLCH, Eyedropper และสีล่าสุด 5 สี)
  - สไตล์: Simple, Metal, Drop Shadow, Double Frame
  - รูปทรง (ปุ่มสัญลักษณ์): สี่เหลี่ยม, มุมมน, วงกลม, สี่เหลี่ยมด้านขนาน, รูปหลายเหลี่ยมกำหนดเอง
- เงาใต้รูป: ทิศทาง (วงหมุน), ระยะ, ความฟุ้ง, ความเข้ม
- Gradient Mask (ใช้ได้ทุกรูปเมื่อมี 2 รูปขึ้นไป รวมรูปล่างสุด): โหมดตัวเลื่อน 2 จุดแนวนอนและแนวตั้ง จางได้พร้อมกันทุกด้าน หรือโหมดอิสระ ระบายด้วยเมาส์/นิ้วบนภาพตัวอย่าง (ส่วนที่ระบายติดไปกับรูป) (ระบายส่วนที่แสดง / ลบ, ขนาดแปรง, แสดงทั้งรูป / ซ่อนทั้งรูป / เริ่มจากตัวเลื่อน) ทั้งสองโหมดปรับความนุ่มของรอยต่อได้
- ปุ่ม "รีเซ็ตทั้งหมด" คืนค่าการปรับของรูปที่เลือก

**ข้อความและองค์ประกอบของ Template**
- Facebook: ข้อความ 3 บรรทัด (บรรทัดบน / พาดหัวหลัก / บรรทัดล่าง) ฟอนต์ Kanit ตามขนาด น้ำหนัก และเงาใน Template (บรรทัดบนขนาด 56 ปรับจาก 52 ตั้งแต่ v1.11.3 แจ้งปรับไซส์โดย **SandSand**) บรรทัดที่ยาวเกินกรอบจะย่อลงเอง โดยขอบตัวอักษรห่างจากขอบซ้ายและขวา 92.3 px (หน่วยของ Template) ระนาบเดียวกับวันที่ (ตั้งแต่ v1.11.4 แจ้งปรับไซส์โดย **SandSand**) ขอบล่างของบรรทัดล่างอยู่กับที่ และระยะห่างระหว่างบรรทัดคงเดิม
- Website: ใช้เฉพาะพาดหัวหลัก 1 บรรทัด (Kanit SemiBold, tracking 20, เงาตาม Template) ย่อลงเองเมื่อยาวเกิน ไม่ตกขอบ และยังอยู่เหนือเส้นชมพู
- สวิตช์ "ใช้พาดหัวหลักร่วมกันทุกแพลตฟอร์ม" (ค่าเมื่อเปิดแอปตั้งได้ในตั้งค่า ค่าเริ่มต้นปิด) ปิดแล้วแต่ละแพลตฟอร์มมีพาดหัวของตัวเอง และ Alternative Text อัตโนมัติใช้พาดหัวของแพลตฟอร์มนั้น
- ตั้งค่า → ขั้นสูง (สวิตช์ “ปรับ Template เอง” ต้องกดยืนยันก่อนเปิด เพราะ Template อิงต้นฉบับจากแผนกกราฟิกดีไซน์และ CI ของบริษัท) ค่าแยกตามแพลตฟอร์ม:
  - ปรับขนาดฟอนต์แต่ละบรรทัด
  - ย้ายตำแหน่ง วันที่ ข้อความทุกบรรทัด โลโก้ เส้น และแถบโซเชียล (ช่อง X, Y, W, H + ปุ่มจัดตำแหน่ง ใต้แต่ละรายการ หรือลากบนภาพ) ทุกรายการเริ่มต้นเป็น **ล็อค** ต้องกดกุญแจปลดล็อคก่อน
  - แถบโซเชียลของ Facebook เปิด–ปิดการแสดงผลได้
  - เมนู “Gradient ดำ” (อยู่ก่อน Alternative Text) เปิด–ปิด ปรับความเข้มและความสูงของ Gradient ของ Facebook / Website แยกกัน
  - ปุ่ม “คืนค่า Template ทั้งหมด” ล้างทุกอย่างที่ปรับในขั้นสูงทุกแพลตฟอร์ม
- คลิกหรือแตะข้อความบนภาพ (Facebook และ Website) เพื่อพิมพ์แก้ได้ตรงนั้น เชื่อมกับช่องข้อความในเมนู (Enter = เสร็จ, Esc = ยกเลิก) และคลิกวันที่บนภาพเพื่อเปิดปฏิทิน
- ปุ่ม "วาง" / "ลบ" แยกทีละบรรทัด, "ข้อความตัวอย่าง" (ใช้ข้อความเริ่มต้นที่ตั้งไว้) และ "ลบทั้งหมด" (เฉพาะ Facebook)
- Facebook: วันที่แบบไทย (ปี พ.ศ.) เลือกจากปฏิทิน (กดชื่อเดือนหรือปีบนหัวปฏิทินเพื่อเลือกเดือน/ปีจากตารางได้เร็วขึ้น) และแถบช่องทางโซเชียล (Website ไม่มีทั้งสองอย่าง)
- เลือกสีโลโก้ (ขาว/ชมพู) และเปิด–ปิดเงาโลโก้ได้ทั้งสองแท็บ
- เส้น: Facebook เลือกขาว/ชมพูได้ Website ใช้เส้นชมพูตาม Template

**Crop & Resize (แท็บไอคอนครอป ต่อจาก Facebook)**
- ครอปและปรับขนาดรูป ไม่มีข้อความ วันที่ เส้น หรือ Gradient ของ Template แต่ปรับรูปได้ครบเหมือน Template อื่น (ลบพื้นหลัง กรอบ เงา Gradient Mask จัดวางอัตโนมัติ)
- โปรไฟล์การดาวน์โหลด (อยู่เหนือปุ่มดาวน์โหลด): "ทั่วไป" ปรับอิสระ ไม่จำกัดขนาดไฟล์ / "รูปข่าวบนเว็บไซต์" ย่อให้ทันที กว้างไม่เกิน 1,200 px และไฟล์ไม่เกิน 200 KB
- ขนาดภาพเริ่มจากครอปของรูปล่างสุด ตั้งกว้าง/สูงเป็น px, %, cm, mm หรือ inch (คิดที่ 72 ppi ตั้งหน่วยเริ่มต้นได้ในตั้งค่า) ปุ่มโซ่ล็อค/ปลดล็อคสัดส่วน (ปลดล็อคแล้วรูปเต็มกรอบโดยไม่บิดเบี้ยว) หรือเลือก ต้นฉบับ / 75% / 50% / 25% (สูงสุด 6000 px ต่อด้าน)
- ปรับ Canvas (แบบ Canvas Size ของ Photoshop) ขยายหรือลดได้ มีลูกศรที่มุมทั้ง 4 ของ Canvas ให้ลากเข้า–ออก (Shift = สองฝั่งเท่ากัน) ขนาดไฟล์ที่ได้แสดงข้างปุ่มรีเซ็ตของขนาดภาพ (Resize) พร้อมภาพตัวอย่างที่ตรงกับ Canvas จริง: ลากขอบออกเพื่อขยาย ลากเข้าเพื่อลด (Shift = สองด้านเท่ากัน) ลากรูปเพื่อเลื่อน ใส่ตัวเลขแต่ละด้าน (ค่าลบ = ลด Canvas เข้าไปในรูป) หรือกดขยายให้เป็นสัดส่วน 1:1 / 4:5 / 3:4 / 16:9 / 9:16
- หน่วยเดียวกันทั้งหน้า Crop & Resize (px / % / cm / mm / inch): ขนาดภาพ ตำแหน่งรูปภาพ ครอป (ช่อง บน/ล่าง/ซ้าย/ขวา แสดงเป็นค่าติดลบ และบอก % ที่หายไปเมื่อใช้หน่วยอื่น) ปรับ Canvas (ช่อง บน/ล่าง/ซ้าย/ขวา บอกหน่วย) และไม้บรรทัด เปลี่ยนที่ช่องไหนหรือคลิกที่ไม้บรรทัดก็เปลี่ยนทุกที่ (% ของตำแหน่งคิดจากขนาด Artboard, % ของระยะขยายคิดจากรูปหลังครอป, cm/mm/inch คิดที่ 72 ppi)
- สวิตช์ใส่/ไม่ใส่โลโก้ เลือกสีและเงาโลโก้ได้ โลโก้วางมุมขวาบนตามตำแหน่งของ Website ย่อ/ขยายตามด้านที่สั้นกว่าของภาพ (จำค่าเปิด–ปิดล่าสุด หรือล็อคไว้ในตั้งค่า)
- ยังมีช่อง Alternative Text เหมือนแท็บอื่น

**การใช้งานทั่วไป**
- ภาษา ไทย / English (US) สลับด้วยปุ่มธงในตั้งค่า จำภาษาไว้ทุกครั้งที่เปิดแอป
- ย้อนกลับ / ทำซ้ำ 30 ครั้ง พร้อมรายการประวัติที่กดข้ามไปจุดไหนก็ได้ แต่ละรายการบอกค่าที่เปลี่ยน และมีปุ่มล้างประวัติ ประวัติแยกตามแพลตฟอร์ม และการสลับแพลตฟอร์มไม่ถูกบันทึก
- ดาวน์โหลดหลาย Template พร้อมกัน: ติ๊กเลือก Website / Facebook / Crop & Resize แยกไฟล์หรือรวมเป็น .zip
- ดาวน์โหลดเป็น JPG เสมอ รูปแบบชื่อไฟล์ "อัตโนมัติ" = `{YYYY}{MM}{DD}{HH}{mm}{ss}-{PLATFORM}-dailynews` ทุก Template หรือ "กำหนดเอง" แยก Website / Facebook / Crop
- Alternative Text ฝังในไฟล์ JPG (XMP `Iptc4xmpCore:AltTextAccessibility` + `dc:description`, EXIF ImageDescription/XPTitle และ IPTC Caption) กรอกอัตโนมัติจากพาดหัวหลัก หรือปิดสวิตช์เพื่อพิมพ์เอง
- ใส่รูปได้ความละเอียดสูงสุด 4096 px ต่อด้าน
- สลับแพลตฟอร์มแล้วรูปตามไปด้วย แต่ตำแหน่ง ขนาด ครอป กรอบ เงา Gradient Mask การจัดวาง และการซ่อนรูป เก็บแยกตามแพลตฟอร์ม

## ลบพื้นหลังทำงานอย่างไร

- ใช้โมเดล **silueta** จาก [rembg](https://github.com/danielgatis/rembg) ซึ่งเป็น U²-Net แบบ quantize แล้ว (ประมาณ 44 MB)
- `tools/convert_model.py` แปลงไฟล์ ONNX เป็นรายการคำสั่ง 253 ขั้น (conv, max-pool, resize, concat, add, sigmoid) และแพ็กน้ำหนักเป็น texture RGBA8
- `src/glnet.js` คำนวณโมเดลด้วย fragment shader ของ WebGL2 จึงไม่ต้องใช้ WebAssembly หรือ Web Worker
  - แบ่งงาน convolution ใหญ่เป็นหลายรอบเล็ก เพื่อไม่ให้การ์ดจอค้างหรือ timeout
  - ผลลัพธ์ตรงกับ ONNX Runtime (ต่างกันไม่ถึง 0.2%)
- ครั้งแรกที่กดจะโหลดโมเดลประมาณ 44 MB หลังจากนั้นเบราว์เซอร์จะแคชไว้
- ต้องใช้เบราว์เซอร์ที่รองรับ WebGL2 และ float render target (Chrome, Edge, Firefox, Safari รุ่นปัจจุบัน)

### สร้างไฟล์โมเดลใหม่ (ไม่จำเป็น ถ้าใช้ไฟล์ใน `model/` อยู่แล้ว)

```bash
# ต้องมี Python 3 และ numpy
curl -L -o silueta.onnx https://github.com/danielgatis/rembg/releases/download/v0.0.0/silueta.onnx
python3 tools/convert_model.py silueta.onnx    # ได้ silueta.json, weights.u8, bias.f32
python3 tools/split_weights.py .               # เขียนลง model/
```

## ข้อจำกัดที่ควรรู้

- **ปุ่ม "วาง":** เบราว์เซอร์บางตัว (หรือเมื่อฝังใน iframe) ไม่ให้เว็บอ่านคลิปบอร์ดโดยตรง ในกรณีนี้แอปจะเลือกข้อความในช่องไว้และแจ้งให้กด `Ctrl+V` / `⌘V` แทน
- **Eyedropper:** ใช้ตัวดูดสีของระบบถ้าเบราว์เซอร์รองรับ (Chrome, Edge) ถ้าไม่รองรับจะให้คลิกดูดสีจากภาพตัวอย่างแทน
- **ไอคอนโซเชียล:** ใน PSB เป็นภาพขนาดเล็ก (~36 px) จึงถูกขยาย 1.33 เท่า ดูใกล้ๆ จะนุ่มกว่าส่วนอื่นเล็กน้อย
- **การตั้งค่า:** จำไว้ใน `localStorage` ของเบราว์เซอร์ที่ใช้ตั้งเท่านั้น ไม่ข้ามเครื่องหรือข้ามเบราว์เซอร์
- **150 KB ของ Website:** นับเป็น 150,000 ไบต์ ภาพที่มีรายละเอียดมากจะถูกลดคุณภาพ JPG ลงจนพอดี ขนาดและคุณภาพที่ได้จะแจ้งหลังดาวน์โหลด
